# amazon-sales-analysis

## Project Overview
This project presents an interactive commercial analysis built in **Microsoft Excel** using a dataset of **1,465 Amazon product records** across 9 product categories. The goal is to evaluate sales performance, order volume, and the impact of discounting strategies.

## Key Features & Methodology
* **Data Structuring:** Cleaned and formatted raw product data (`product_id`, `category`, `actual_price`, `discounted_price`, `discount_percentage`) into a dynamic Excel Table with summary KPI formulas.
* **Pivot Tables & Charts:** Created three dedicated analytical views:
  * **Sales Summary (`sumar vanzari`):** Compares total actual revenue vs. discounted revenue across categories.
  * **Orders Summary (`sumar comenzi`):** Tracks order distribution by product category (led by Electronics, Computers & Accessories, and Home & Kitchen).
  * **Discounts Summary (`sumar reduceri`):** Analyzes average discount percentages per category.
* **Interactive Filtering:** Integrated category **Slicers** connected to the pivot views for quick, dynamic exploration.

## Tools Used
* **Microsoft Excel** (Excel Tables, Formulas, Pivot Tables, Charts, Slicers)
